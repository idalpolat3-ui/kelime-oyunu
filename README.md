# 6 Sefer Tekrar Prensibi ile Kelime Ezberleme Oyunu

## Proje Hakkında
Bu proje, İngilizce kelimeleri 6 sefer tekrar prensibi ile öğrenmeyi sağlayan bir web uygulamasıdır.

## Özellikler
- Kullanıcı kayıt ve giriş sistemi
- Kelime ekleme (İngilizce, Türkçe, resim)
- 6 sefer algoritması ile sınav modülü
- Analiz raporu
- Wordle bulmacası
- Word Chain + LLM hikaye oluşturma

## Kurulum
1. Python yükleyin
2. `pip install flask flask-sqlalchemy flask-login google-genai` çalıştırın
3. `python app.py` ile başlatın
4. Tarayıcıda `http://127.0.0.1:5000` adresine gidin

## Teknolojiler
- Python + Flask
- SQLite
- Bootstrap 5
- Google Gemini API
